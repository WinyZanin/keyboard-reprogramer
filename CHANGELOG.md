## [0.1.0] - 2026-11-17

### Added

- Native Win32 window to remap any physical key to a media action (Play/Pause, Next,
  Previous, Stop, Volume +/-, Mute), with one row per key, per-row and global enable/disable,
  and a trigger history.
- Key capture by pressing the key; keys identified by scan code.
- English and Portuguese (Brazil) interface, following the Windows display language.
- Help → About showing the version.
- Single instance: launching the app again brings the open window to the front.
- Inno Setup installer and MSI (per-user by default, no admin), portable zip and
  SHA256 checksums, published by GitHub Actions.
